# CHANGELOG — STUDY LAB

All notable changes to the STUDY LAB project are documented in this file.

## [2.0.0] - 2026-11-12
### Added
- **Full Interactive Platform**: Built all 5 primary bottom navigation modules (Home, Study, Brain, Skills, Profile).
- **Procedural Sound Engine (`soundEngine.ts`)**: Pure Web Audio API synthesizers for 528Hz timer bells, binaural 40Hz alpha wave focus soundtrack, tactile tap clicks, and multi-oscillator level-up fanfare.
- **Dual Presentation Mode (`DeviceFrame.tsx`)**: Authentic Infinix Smart 9 Android smartphone shell with status bar, punch-hole camera, gesture bar, rotate, and desktop expansion switch.
- **Academic Management**: Full hierarchy (Subjects, Chapters, Units, Lessons) with 4 status states, priorities, deadlines, tasks, and editable templates for Calculus, Quantum Physics, Algorithms, and Languages.
- **Memory Engine**: SuperMemo SM-2 spaced repetition calculation, 3D interactive flip cards, and review scheduling.
- **Brain Gym Suite**: Four playable mental challenge generators (Deductive Logic, Number Sequences, Quick Math, Memory Matrix) with step-by-step solutions and explanations.
- **Deep Focus**: Pomodoro presets (25/5, 50/10, Custom) with circular SVG timer, background reload survival, and subject/skill linking.
- **RPG Progression**: Level 1–100 formula, Rank Tiers (E, D, C, B, A, S), daily/weekly quests, achievements, visual Skill Tree across 7 disciplines, and immutable XP transaction ledger.
- **Analytics & Backup**: Study statistics, JSON export/import for local backups, and cloud synchronization abstraction layer.
- **Bilingual Arabic/English (`i18n.ts`)**: Complete translations with automatic RTL/LTR direction switching and persistent preference.
- **Android Studio Project Structure**: Full Kotlin/Compose/Room source repository files (`app/src/main/java/com/studylab/app/...`, Gradle catalog, ProGuard rules, AndroidManifest) with in-app Code Explorer.
- **One-Click Android Project Zip Exporter (`projectExporter.ts`)**: Export the complete ready-to-build Android Studio project bundle directly into a `.zip` archive on demand.
